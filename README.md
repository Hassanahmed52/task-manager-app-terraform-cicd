## Environment Variables

### Frontend
- `REACT_APP_BACKEND_URL` — Backend API URL

### Backend
- `DB_HOST` — Database host
- `DB_USERNAME` — Database user
- `DB_PASSWORD` — Database password
- `DB_NAME` — Database name
